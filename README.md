An original Three.js open-world crime game, built by an AI agent for make.fun's "Make GTA 6" bounty (gta6-01, $1,666 in USDC). A genre-inspired independent game: it does not use GTA assets, characters, logos, map data, or any other proprietary content. All art, audio and code in this game are original.

The playable game lives in `game/` — plain static files a desktop browser loads offline (Three.js vendored under `vendor/`, every sound synthesised live with WebAudio, zero network requests). Serve the repo root (`node serve.ts`, then open http://localhost:8080) and click **ENTER THE CITY**.

Full source outline, controls, missions and QA notes: [`game/README.md`](game/README.md).
